# Student Management System

## Project Description
The Student Management System is a simple Python application developed using Object-Oriented Programming (OOP) concepts. It allows users to add, display, and search for student records and calculate their grades based on marks.

## Features
- Add new student records.
- Display all registered students.
- Search for students using their roll number.
- Automatically calculate grades based on marks.
- Validate marks entered by the user.

## OOP Concepts Used

1. **Classes and Objects:** The program uses Student and StudentManagement classes to organize data and functionality.
2. **Constructors:** The `__init__()` method initializes student details and the management system.
3. **Encapsulation:** Student marks are stored in a private attribute (`__marks`) and accessed through a method.
4. **Methods:** Functions inside classes perform operations such as adding students, displaying details, and calculating grades.
5. **Object Management:** Student objects are stored in a list for easy access and management.

## Technologies Used
- Python 3
- Object-Oriented Programming

## How to Run
1. Download the `student_management.py` file.
2. Open it using Python IDLE or any Python IDE.
3. Run the program.
4. Select an option from the menu and follow the instructions.
